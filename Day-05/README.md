## 🧠 Main Concepts I Learned

### 🌐 Networking Basics

Learned the fundamentals of computer networking and how devices communicate with each other.

Important concepts included:

- IP Addresses
- Network Devices
- Protocols
- Hosts
- Network Communication

Understanding networking is essential for cybersecurity because most modern systems communicate over networks.

---

### 🏠 Local Area Network (LAN)

Learned what a Local Area Network is and how devices communicate within a local environment.

A LAN can connect devices such as:

- 💻 Computers
- 📱 Phones
- 🖨️ Printers
- 🌐 Network Devices

---

### 🧅 OSI Model

Learned the seven layers of the OSI model and how network communication can be divided into different layers.


7 — Application
6 — Presentation
5 — Session
4 — Transport
3 — Network
2 — Data Link
1 — Physical

The OSI model provides a structured way to understand where different protocols and networking technologies operate.

📦 Packets & Frames

Learned the difference between packets and frames and how data is encapsulated while travelling through a network.

Understanding packets and frames is important for analysing network traffic and troubleshooting communication.

🌍 Extending Networks

Learned how networks can be expanded and how devices such as switches and routers help connect devices and different networks.

This helped me understand how small networks can communicate with larger networks and eventually the internet.

🎯 Key Takeaway

Networking is one of the most important foundations of cybersecurity because both attackers and defenders interact with systems, services, and data through networks.
