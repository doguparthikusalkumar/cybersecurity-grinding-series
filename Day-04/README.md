## 🧠 Main Concepts I Learned

### 🔢 Data Representation

Learned how computers represent information digitally using binary and how different types of data can be represented as numbers.

Understanding data representation is important because computers ultimately process information in digital form.

---

### 🔤 Data Encoding

Learned that encoding allows information to be represented in a format that systems can understand and process.

This is especially important in cybersecurity because encoded data can frequently appear during investigations and web security testing.

---

### 🐍 Python

Got an introduction to Python and how programming can be used to automate tasks and process information.

Python will become particularly useful later for:

Learned how databases store and retrieve information and got introduced to SQL.

Understanding SQL will also be useful when learning about web application vulnerabilities later.
