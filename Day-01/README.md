# 📅 Day 01 — Introduction to Cyber Security

## 🎯 Today's Focus

Started my cybersecurity journey by understanding what cybersecurity actually means, the difference between offensive and defensive security, and the different career paths available in the field.

- 🛡️ Defensive Security Intro

---

## 🧠 Main Concepts I Learned

### ⚔️ Offensive Security

Learned about the mindset of an attacker and how security professionals simulate attacks to identify weaknesses in systems.

The goal isn't simply to "hack" something, but to:

- Find vulnerabilities before real attackers can exploit them
- Understand how attackers think
- Identify weaknesses in systems
- Help organizations improve their security

### 🛡️ Defensive Security

Learned how defenders protect systems, networks, and applications from attacks.

This includes:

- 🔍 Monitoring
- 🚨 Detecting suspicious activity
- 🔎 Investigating incidents
- 🛑 Responding to attacks
- 🔧 Improving security controls

### 💼 Careers in Cybersecurity

Got an introduction to different cybersecurity career paths and realized that cybersecurity is a broad field rather than a single job role.

Some examples include:

- Penetration Testing
- Security Operations
- Incident Response
- Digital Forensics
- Security Engineering
- Threat Intelligence

---

## 🎯 Key Takeaway

> Cybersecurity involves both attacking and defending systems. Understanding how attackers think helps defenders build stronger security.
