## 🧠 Main Concepts I Learned

### 🖥️ Inside a Computer System

Learned the basic components that make up a computer system and how they work together.

Important concepts include:

- 🧠 CPU
- 💾 RAM
- 💿 Storage
- ⌨️ Input/Output
- ⚙️ Processing

Understanding these fundamentals is important because cybersecurity ultimately protects computing systems and the data running on them.

---

### 💻 Computer Types

Learned that computers exist in many forms and aren't limited to traditional desktop PCs.

Different computing devices can have different:

- Hardware
- Operating systems
- Resources
- Security requirements

---

### 🌐 Client-Server Model

Learned the basic relationship between a client and a server.

Client
   │
   │ Request
   ▼
Server
   │
   │ Response
   ▼
Client

For example:

Browser → Web Server → Webpage

This became especially useful later when learning HTTP.

📦 Virtualisation

Learned how virtual machines allow multiple virtual computers to run on a single physical machine.

Virtualisation is especially relevant to cybersecurity because security labs commonly use virtual machines for:

🐉 Kali Linux
🪟 Windows environments
🎯 Vulnerable machines
🧪 Testing environments
☁️ Cloud Computing

Learned the basic idea of cloud computing and how computing resources can be provided through remote infrastructure instead of being hosted entirely on a local machine.

🎯 Key Takeaway

Understanding how computers and computing environments work is essential before learning how to secure or attack them.
