## 🧠 Main Concepts I Learned

### 🖥️ Operating Systems

Learned that an operating system acts as an interface between the user, applications, and hardware.

It manages resources such as:

- 🧠 CPU
- 💾 Memory
- 💿 Storage
- ⚙️ Processes
- 👤 Users
- 🔌 Devices

---

### 🪟 Windows

Learned the basic structure and functionality of Windows systems.

Understanding Windows is important because it is widely used in personal computers, organizations, and enterprise environments.

---

### 🐧 Linux CLI

Started understanding how to interact with Linux through the command line.

This is particularly important for cybersecurity because Linux is heavily used in:

- 🎯 Penetration Testing
- 🔬 Security Research
- 🖥️ Servers
- 🛠️ Security Tools
- 🚩 CTF Environments

---

### 💻 Windows CLI

Learned the basics of interacting with Windows systems through the command line.

Command-line knowledge is useful for administration, troubleshooting, automation, and cybersecurity operations.

---

### 🔐 Operating System Security

Learned that operating systems need security controls such as:

- 🔑 User Permissions
- 🔐 Authentication
- 🚪 Access Control
- 🔄 Security Updates
- ⚙️ Secure Configuration

These controls help prevent unauthorized access and protect system resources.

---

## 🎯 Key Takeaway

> The operating system is the foundation on which applications and security tools run, so understanding both Linux and Windows is essential for cybersecurity.
